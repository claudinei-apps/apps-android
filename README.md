# apps-android

Apps Android do Claudinei (APK de teste/debug). Cada app fica em `apps/<nome>/`; `_modelo/` é o ponto de partida.
O workflow **APK debug** compila a pasta escolhida e publica o APK em um Release `<nome>-latest` (download sem login).
Repositório público: nunca coloque senhas, chaves ou dados de clientes no código.
